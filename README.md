# endangered-species-binary-search-tree-DS
Date Submitted: October 25, 2024
Last Updated on GitHub: April 10, 2026

This repository contains my complete work for the binary search tree project of CISC220: Data Structures at the University of Delaware College of Engineering Department of Computer and Information Sciences. I completed this course in the Fall of 2024, with Professor Leighanne Hsu being the course instructor. The purpose of this course was to introduce students to topics such as data type abstraction, recursion, arrays, stacks, linked lists, dynamic storage management, trees, graphs, tables, sorting, searching, and more.

This specific project dealt with a binary search tree, a key concept for the course. The objective of this project was for students to write methods associated with a binary search tree whose data type is a species of animal. The Species class has three fields: the name of the species as a string, the endangerment status as a string, and more information as a string. For this project, I created the following methods: the constructor, insert, *find, printTreeIO, printTreePre, printTreePost, updateStatus, *removeNoKids, *removeOneKid, *remove, and setHeight. After creating these methods, I tested them with the provided data sets.

Three folders were created for this repository. The 'header-source-files' folder contains the four C++ header source files given to students from Professor Hsu. Next, the 'source-files' folder contains the five C++ source files that I had to complete for this project. The 'species' folder contains the two species data sets used for this project.
